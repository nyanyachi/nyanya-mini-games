Game Details

About This Game

Dice Roller is a simple utility-style game that rolls one virtual six-sided die. Each roll shows a number from 1 to 6 on a CSS dice face, then updates the total roll count and the count for that result. It is useful when you want a quick random result without physical dice, while still keeping a lightweight history of how often each face has appeared in this browser.

How to Play

  1. Press Roll Dice to roll the die.
  2. Read the number shown on the dice face.
  3. Check Last Roll for the most recent result.
  4. Review Total Rolls and the counts for faces 1 through 6.
  5. Use Reset Statistics when you want to clear the saved roll history.

Rules

  • Each roll randomly produces one result from 1 to 6.
  • Every roll increases Total Rolls by 1.
  • Only the count for the rolled face increases.
  • Roll totals are saved locally in this browser.

Tips

  • Use Reset Statistics before starting a separate tracking session.
  • Check the face counts if you want to see the spread of results over many rolls.
  • Roll one at a time when you need a single clear result.
  • Keep the page open if you want to continue the same local session.
