Game Details

About This Game

Sudoku is a number puzzle played on a 9 by 9 grid divided into 3 by 3 boxes. The goal is to fill every empty cell so each row, column, and box contains the numbers 1 through 9 without duplicates. This version includes Easy, Medium, and Hard puzzles, mistake tracking, a timer, keyboard input, an on-screen number pad, and best-time saving for each difficulty.

How to Play

  1. Choose Easy, Medium, or Hard.
  2. Select an empty cell on the board.
  3. Enter a number using the keyboard or on-screen number pad.
  4. Use the row, column, box, and matching-number highlights to review the board.
  5. Complete every cell without breaking Sudoku rules.

Rules

  • Fixed clues cannot be changed.
  • Each row must contain 1 through 9 without duplicates.
  • Each column must contain 1 through 9 without duplicates.
  • Each 3 by 3 box must contain 1 through 9 without duplicates.
  • Best times are saved separately by difficulty after completed puzzles.

Tips

  • Start with rows, columns, or boxes that already have many clues.
  • Use matching-number highlights to spot where a number is already placed.
  • Check intersections before entering a number in a crowded area.
  • If mistakes rise, slow down and verify the row, column, and box together.
