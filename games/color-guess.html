Game Details

About This Game

Color Guess is a visual comparison game about matching a target color swatch to the correct answer choice. Each round shows one target and three color options, with one option matching exactly. The game tracks score, total attempts, and the best score saved in this browser. It is quick to play, but close colors can still make a round feel like a small observation challenge.

How to Play

  1. Look at the target color swatch.
  2. Compare it with the three answer choices.
  3. Select the choice that matches the target.
  4. Read the Correct or Try again feedback.
  5. Use New Round when you want another set of colors.

Rules

  • One answer is correct in each round.
  • A selection increases total attempts.
  • Correct answers increase the score.
  • Best Score saves the highest score reached in this browser.
  • Reset Statistics clears the saved best score and current tracked totals.

Tips

  • Compare brightness and saturation, not just the basic hue.
  • Look away for a second if two choices feel too similar.
  • Use the target swatch as the reference instead of comparing choices to each other first.
  • Play several rounds to see whether your score stays consistent.
