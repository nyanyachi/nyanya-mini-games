Game Details

About This Game

2048 is a sliding tile puzzle played on a 4 by 4 board. Each move shifts every tile in one direction, and equal-number tiles merge into a larger value. New 2 or 4 tiles appear after valid moves, gradually filling the board. The main objective is to reach the 2048 tile, but the board can continue beyond that milestone if moves remain available.

How to Play

  1. Use Arrow keys on desktop or swipe on touch screens.
  2. Slide all tiles up, down, left, or right.
  3. Merge tiles with the same number to create larger values.
  4. Use Restart when you want to begin a fresh board.
  5. Watch the score and best score as tiles merge.

Rules

  • Only matching values merge during a move.
  • Each tile can merge once per move.
  • A new tile appears after a valid board change.
  • The game is over when the board is full and no merges are available.
  • Best score is saved locally in this browser.

Tips

  • Keep larger tiles near one corner when possible.
  • Avoid scattering high-value tiles across the board.
  • Think about where the next new tile could create trouble.
  • Do not swipe randomly when the board is crowded.
