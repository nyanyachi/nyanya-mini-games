Game Details

About Tower of Hanoi

Tower of Hanoi is a classic logic puzzle about moving a stack of disks between three pegs. The goal is simple, but every move must respect the disk order.

How to Play

  1. Move the complete tower from the left peg to the right peg.
  2. Move only one disk at a time.
  3. Only the top disk of a peg can be moved.
  4. Never place a larger disk on top of a smaller disk.
  5. Complete the puzzle using as few moves as possible.

Rules

  • Choose 3, 4, 5, or 6 disks before starting a new puzzle.
  • The minimum possible move count is 2^n - 1, where n is the disk count.
  • Invalid moves are ignored and do not increase the move counter.
  • The timer starts after the first valid move and stops when the puzzle is complete.

Tips

  • Try to move the smallest disk often; it helps unlock larger disks.
  • Use the middle peg as temporary storage while building the final tower.
  • Restart if you want to practice the same disk count from the beginning.

Controls and Saving

Click or tap pegs to select and move the top disk. Keyboard users can focus the board, press 1, 2, or 3 to choose pegs, and press Escape to clear a selection. Best results are saved separately for each disk count in this browser.
