Game Details

About This Game

Hangman is a word guessing game where a hidden word is shown as blank letter slots. Choosing a correct letter reveals every matching position in the word, including repeated letters. Incorrect guesses increase the mistake count, and the round is lost after six wrong letters. The game uses a local word list, on-screen A to Z buttons, and optional keyboard letter input for quick play.

How to Play

  1. Start with the blank word slots.
  2. Choose letters from the on-screen keyboard or type a letter.
  3. Watch correct guesses reveal all matching letters.
  4. Avoid reaching six incorrect guesses.
  5. Use New Game to reset and choose a new random word.

Rules

  • Each letter can be guessed only once per round.
  • Correct repeated letters are revealed together.
  • Six incorrect guesses causes a loss and reveals the answer.
  • The player wins when every letter in the word is revealed.
  • The game does not use saved score statistics.

Tips

  • Start with common vowels to reveal the word shape.
  • Look for repeated patterns before guessing rare letters.
  • Use common consonants like T, R, S, and N when the word has several blanks.
  • After a few letters appear, think about full word possibilities before choosing again.
